# Peak

App personal de seguimiento de hábitos, instalable como PWA en celular y portátil.

Cada día marco mis hábitos en una checklist de colores, y una gráfica en forma
de montaña sube o baja según qué tan constante fui durante la semana.

> Proyecto de uso personal, construido con prácticas profesionales.

## Estado

🚧 En desarrollo. Fase actual: 0 (cimientos).

## Funciones previstas

- Checklists diarios por hábito, cada uno con su color
- Gráfica de montaña con el progreso diario a lo largo de la semana
- Días de la semana propios para cada hábito
- Recordatorios con notificaciones push
- Instalable como PWA en celular y portátil
- Datos guardados en SQLite, con respaldo exportable

## Stack

HTML5 · CSS · JavaScript · Node.js · Express · SQLite · Web Push
